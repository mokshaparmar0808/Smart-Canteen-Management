# Smart Canteen Management System

This is a database project for managing a canteen system.

It contains information about users, food items, categories, orders, order items and payments.

## Database

The database is created using SQLite.

### Tables

- Users
- Categories
- FoodItems
- Orders
- OrderItems
- Payments

## Files

- `canteen.db` - Main SQLite database
- `Categories.csv` - Category data
- `FoodItems.csv` - Food item data
- `OrderItems.csv` - Order item data
- `Orders.csv` - Order data
- `Payments.csv` - Payment data
- `Users.csv` - User data

## Tools Used

- SQLite
- DB Browser for SQLite
- SQL
- CSV

## About the Project

This project was made to practice database concepts such as creating tables, storing data, connecting tables using relationships and working with SQL queries.

The data used in this project is sample data for learning purposes.
